## 2. Definition of Done

- 功能有对应 FR 编号、单元测试和集成测试；
- API 有成功、鉴权失败、状态冲突和幂等重复用例；
- 任何补丁都能追溯到 finding、patch_version、sandbox_run 和 approval；
- 任何副作用操作都有权限、状态和审计记录；
- 安全不变量全部为 0；
- README 能在干净环境说明启动、评测和清理步骤。

## 3. 验收矩阵

| 类别 | 必测用例 | 通过条件 |
|---|---|---|
| 输入 | 空 Diff、非法 ZIP、路径穿越 | 返回 `INVALID_INPUT` |
| Agent/A2A | 15 步超限、重复工具调用、Card 不兼容、Artifact 非法 | 转人工或返回明确错误码 |
| 权限 | developer 审批、写 main 分支 | 返回 `FORBIDDEN` |
| 补丁 | 非法格式、文件冲突、Scope Drift | 不产生文件副作用 |
| 沙箱 | 外网、提权、写 `/etc`、超时 | 被阻断并清理资源 |
| 测试 | 基线失败未修复、覆盖率下降、TEST_GAP | 质量门禁失败 |
| 审批 | 旧版本审批、拒绝无原因 | 返回 `VERSION_CONFLICT` 或 `INVALID_INPUT` |
| 评测 | 20 PR、轨迹、pass@3/pass^3 | 达到 SRS 指标 |
| 恢复 | SSE 断线、Agent 超时、Coordinator 重启、未知状态 | 状态可查询并收敛，不重复副作用 |

## 4. 风险与降级

- Docker 不可用时只允许运行规则和报告链路，禁止在宿主机执行提交代码；
- LLM 不可用时输出规则和 AST 结果，Fix Agent 进入 `NEEDS_HUMAN`；
- P1 的符号索引、Git 历史和向量检索可降级为空实现，但必须保留接口和 `schema_version`；
- 评测结果必须区分 OFFLINE 与 LLM 模式，不能混合统计。
